BREmote V2.5-Evo — Setup Wizard

Prototype. Answer the questions, get a config for the remote and a config for the buggy. About 8 minutes.
Only for BREmote V2.5-Evo firmware (the fm-stations nightly: buggy SW 36 and remote SW 27 from that branch; older SW 36/27 builds and master lack some of these settings). The settings this wizard writes do not exist in Ludwig's stock BREmote firmware: do not use it with stock firmware, or with older V2.5-Evo builds. Check the version your board prints at boot (?conf shows "version") before pasting anything.
Browse mode is on: flip to any page with the chips or Back/Next, no answers needed. Unanswered questions use the recommended choice, so the Results page always shows a full example config. Turn Browse mode off to answer the questions for your own setup. New in the upcoming release: in the nightly builds on the fm-stations branch now; it moves to master gradually after more water testing.
